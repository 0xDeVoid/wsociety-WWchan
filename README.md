# WWchan 👺🍀🌐

> Когда Reddit слишком душный, а 4chan пугает своей первобытностью.

WWchan — это попытка взять лучшее из двух миров. Мы скрестили удобные древовидные комменты с духом старых имиджборд, где правит анонимность, шитпостинг и свобода слова. Никаких «умных» корпоративных лент и теневых банов - только чистый контент, ламповые треды и база.

## 🛠 Стек технологий

Мы не любим ждать, поэтому собрали всё на быстрых и адекватных тулзах:
* **Фронт:** React, JavaScript и Vite (собирается быстрее, чем ты успеваешь моргнуть). Сетка и UI собраны по красоте на CSS Flexbox и Grid.
* **Бэк:** GoLang (работает быстро, фиксится стильно).
* **База:** PostgreSQL и Draw.io. (хз)
